# 精度管理サーベイ入力画面の観察メモ(模擬画面づくりの仕様)

観察日: 2026-11-03。対象は、実在する精度管理サーベイの Web 入力画面(名称・施設・回答値は記録しない)。
目的: 拡張機能のテストで使う模擬画面 (`test-page/eqa/`) を、実際の入力作業に近い作りにするための仕様。
方針: ここに書くのは**構造と見た目の目安**だけ。実画面の文言・画像・ロゴ・HTML・CSS は複製しない。模擬画面の施設名・数値はすべて架空にする。
観察は読み取りのみで、入力・保存・送信はしていない。

## 画面の構成
- トップ: 告知が全文のまま長く並ぶ一覧と、4つの業務メニュー(事務/基本マスタ/回答入力/データ分析)。
- 回答入力メニュー: 事業・コースの行を「選択」してから、別のボタン「回答入力」を押す2段階。選択後の見た目の変化が小さい。
- 回答入力は 9 タブ: 検査項目別 / 試料別 / 測定装置一括 / 試薬一括 / 検量一括 / 基準値一括 / 実施状況一括 / 未入力チェック / 内部精度管理報告。
  1項目の回答が最大6タブに分散する。

## 画面ごとの仕様

### A. 項目一覧(検査項目別回答)
- 41 項目の表。列は 回答ボタン / 状況 / 評価 / コード / 項目名称 / 略称。1行 約23px。
- 行は白と薄い黄色の交互。見出しは水色。選択行は明るい緑。
- 「回答」ボタンを押すと、数秒の読み込み表示のあと、項目ダイアログが開く。

### B. 項目ダイアログ(縦スクロール、約 900x620px)
- 上から: 項目名 → 測定日(日付欄+選択+「今日」ボタン)→ 試料ごとの結果欄(右寄せ数値+単位+桁数表示)
  → 青い注意文 → 測定装置 / 試薬 / 方法 / 検量 / 製造販売元 / 標準液 / 基材 / 上位標準 / 表示値設定企業 / 販売企業 / トレーサビリティ
  (灰色の読み取り欄+右に「選択」ボタン)→ 基準範囲(共通・男性・女性の下限〜上限)→ 採用基準 → 理由(任意)→ 実施状況 → フリーコメント。
- 赤い注意文が欄の下に点在する。
- 下部のボタン: 「保存して閉じる」「キャンセルして閉じる」。最下段に「保存して次の項目へ」。
- 「選択」ボタン: 欄の直下に小さな検索パネル(検索名称+検索+選択クリア+件数+候補表)がダイアログ内で展開する。ダイアログの下端で見切れる。

### C. 試料別の一覧
- 左に、検査分野・項目分類・試料のチェックボックスと「表示」「クリア」。「表示」を押すまで表は空。
- 上部: 保存 / キャンセル・再表示 / ローカルファイル選択 / アップロード。左下に入力用 Excel のダウンロードリンク。
- 表: 検査項目 / 種別 / 桁数 / 単位 / 測定日(日付+今日ボタン)/ 試料列(数値入力欄)。29項目×試料。定性項目の行は選択ボックス。
- 入力できるのは測定日と結果のみ。装置・試薬などは別タブ。

### D. 未入力チェック
- 未入力の項目だけを一覧にする。値の妥当性(桁・入れ違い・単位・範囲)は見ない。

## 共通の見た目(目安)
- 画面幅 1311px で観察。背景白、文字黒、12px。フォントは MS Pゴシック → Verdana → sans-serif。
- 上部に緑〜水色のグラデーション帯(高さ約 68px)。左に事業名の濃緑バー、右に施設表示の青バー、右上に小さなリンク群。
- タブは角丸の灰色、選択中は緑。左に検索条件の枠(約 175px 幅)。
- 入力欄は白背景・数値は右寄せ。読み取り専用欄は灰色背景。色は目視の推定値で、正確な数値は取っていない。

## 拡張機能のテストに効くポイント(模擬画面に入れる)
1. **ダイアログ内の入力**: ページ本体ではなくダイアログ内の欄を記録できるか。
2. **「選択」ボタン経由の入力**: 欄が読み取り専用で、値は別パネルから入る。通常の入力イベントが出ない。
3. **タブをまたぐ回答**: 1項目の内容が複数画面に分かれる。送信前ゲートの一覧に、全タブの内容を載せられるか。
4. **試料別の一覧入力**: 表の多数の欄・測定日の一括入力・Excel アップロードによる一括反映(貼り付けと別経路)。
5. **「保存して次の項目へ」**: 保存と画面遷移が同時に起きる操作を、ゲートが捕捉できるか。
6. **未入力しか見ない確認**: 入れ違い・桁ミスを画面側が止めない状況を再現する(これが拡張機能の存在理由)。
