# 入力監査ログ (Input Audit)

ブラウザでの入力・貼り付け・フォーム送信を記録するローカル監査拡張 (Chrome / Edge, Manifest V3)。

## 試してみたい方へ

現在は試用版 (v0.2.0) を GitHub で配布しています。Chrome ウェブストアにはまだ出していません。
**[試用インストール手順 (INSTALL.md)](INSTALL.md)** のとおりに、ZIP をダウンロードしてブラウザに読み込むだけで使えます（3分ほど）。
感想や不具合は Issues からお知らせください。

## 記録モード

- **既定 (全サイト)**: メタデータのみ。入力値は保存しない。
- **値を記録するサイト (許可リスト)**: ポップアップの「値を記録するサイト」に追加したホストでだけ、入力値・修正履歴 (`92 → 98`)・送信/ボタンクリック時の入力一式 (スナップショット) も保存する。項目名が取れない表形式フォーム向けに、同じ行の文字 (`context`) も残す。
- パスワード欄は許可リストに関係なく常に値を扱わない。
- 想定用途: 外部精度管理サーベイ等のWeb入力で、入力ミスがどの時点で起きたかを後から追う。対象は精度管理試料のみ (患者情報は入力しない前提)。

## 記録するもの / しないもの (既定モード)

| 記録する | 記録しない |
|---|---|
| 時刻、URL (クエリ・ハッシュ除く)、入力欄の属性 (tag/type/name/id/label) | **入力値そのもの** |
| 文字数 | パスワード欄の値・文字数 |
| 機密らしさの種別 (creditCard / apiKey / privateKey / jwt / email / phoneJP / digits12) | |
| 送信先オリジン、別オリジン送信・非HTTPS送信の有無 | |

保存先は `chrome.storage.local` のみ (最大5000件・約8MB、超過分は古い順に削除)。値は1項目2000文字、スナップショットは300欄で切り詰める。外部送信はありません。


## セキュリティとデータの扱い (管理部門・情シス確認用)

施設・組織での利用を検討する際の確認用に、データの扱いをまとめます。

- **保存先**: ログは利用者のブラウザ内 (`chrome.storage.local`) にのみ保存されます。外部サーバーへの送信・同期は一切ありません (ネットワーク通信を行うコード自体がありません。ソースコードは本リポジトリで確認できます)。
- **記録範囲**: 既定では入力値そのものは記録せず、時刻・欄の識別情報・文字数などのメタデータのみです。入力値・修正履歴・送信時スナップショットは、利用者が許可リストに登録したサイトでのみ記録します。
- **パスワード**: パスワード欄は、許可リストのサイトでも値・文字数とも記録しません。
- **第三者からの読み取り**: Web ページ側からログを読む仕組みはありません。保存領域は拡張機能ごとに分離されているため、他の拡張機能からも読めません。
- **平文保存について**: 許可リストのサイトで記録した値は、ブラウザのプロファイル内に平文で保存されます。端末自体がマルウェア等に侵害された場合には読み取られる可能性があるため、個人情報そのものを入力するサイトは許可リストに登録しないでください。本ツールの想定対象は、精度管理試料の測定値など、個人情報を含まない入力です。
- **保持と削除**: 保存上限は 5000 件・約 8MB で、超過分は古い順に削除されます。自動消去期限は設けていないため、業務で利用する場合は作業後の全削除など、運用ルールをあわせて決めてください。削除はポップアップの「全削除」からいつでも可能です。
- **権限**: 拡張機能が使う権限は `storage` と `activeTab` のみです。

## インストール (開発版)

- Chrome: `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」→ `extension/`
- Edge: `edge://extensions` → 開発者モード → 「展開して読み込み」→ `extension/`

シークレット/InPrivate は、拡張機能の設定で許可しない限り記録されません。

## 制限

- 検出は正規表現ベースで、誤検知・見逃しがあります (`digits12` は特に誤検知しやすい)。
- 入力イベントは 800ms デバウンスして 1 欄 1 件にまとめます。キー単位の記録はしません。
- ページのスクリプトが作った偽イベント (`isTrusted` でないもの) は記録しない。そのため `form.requestSubmit()` 等で JS が送信するサイトでは submit は残らず、送信ボタンの実クリック (スナップショット付き) が残る。
- `fetch` / XHR による JS からの送信は捕捉しません (フォームの submit のみ)。
